# Trechos de código

Arquivos reais do projeto, copiados sem alteração:

- `BlockerRules.kt`: regras de decisão do bloqueio, sem nada do Android.
- `BlockerRulesTest.kt`: testes dessas regras.
- `limits.ts`: plano de limite de tempo com redução gradual.

Os comentários refletem fases anteriores do desenvolvimento (por exemplo, falam em protótipo e citam um documento interno). O app atual usa o uso real medido pelo Android.
